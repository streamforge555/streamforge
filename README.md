# Streamforge

Tools that make StripChat easier and more enjoyable for streamers and viewers.

---

## Available Tools

### 🎯 Request Window

Displays only tipped requests in a separate window.

Features
- Shows only paid requests
- Easy-to-read popup
- Hides 1-token spam

---

### 💰 Coin Spending Display

Displays an estimated spending amount based on StripChat coins.

Features
- Real-time coin to currency conversion
- Supports multiple currencies
- Double-click to reset

## Experiments

### 🎥 Tiny2 Viewer Camera Control

Experimental StripChat viewer camera control for **OBSBOT Tiny 2**.

Authorized viewers can use strict public-chat commands to pan, tilt, and zoom the camera while the designated camera-control request is active.
