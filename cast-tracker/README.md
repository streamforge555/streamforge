# Streamforge Cast Tracker (CT)

**Cast Tracker** is a companion analysis tool for **Streamforge Stream Recorder**, not a product for sale.

It helps observe and compare patterns in StripChat livestreams using recorded and live observations.

## Research focus

- Audience counts and changes over a broadcast
- Public-room traffic and engagement
- Chat activity and token-holder indicators
- Ticket Show and Group Show participation and pricing patterns
- Differences between viewer counts, participation and activity

## How it fits into Streamforge

**Stream Recorder → Cast Tracker → Analysis articles**

Stream Recorder captures observations. Cast Tracker helps examine and compare them. Findings and hypotheses are discussed in Streamforge's note articles.

The observations are exploratory: they do not reveal StripChat's private ranking or recommendation algorithms.

## Availability

This repository page documents the companion research tool. **CT is not offered for sale and no public release or source code is provided here.**
